# Budget-Calculator
  My first pet-project!
================================================================================================================================================================================================================================
Hi everyone who is reading this! This is my first pet-project dedicated to a budget calculator. In it, you can add a certain amount of income and categories of percentage distribution — to which area you would like to allocate your money. You can also add your own categories to set your own distribution percentages. The code is still in early access; the project will be gradually refined. A database will be connected to store data on income distribution, with data displayed on a graph.
================================================================================================================================================================================================================================
